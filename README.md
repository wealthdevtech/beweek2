This is a basic Task CRUD API, built using NodeJS and ExpressJS.

I chose SQLite as my database because, as a beginner, seeing so many database options like PostgreSQL, MySQL, ETC. and discovering the learning curves and numerous setup instructions, it became overwhelming and discouraging to actually start with a project. I have discovered that SQLite has no installation or configuration requirements, and that it also holds the ENTIRE database in one file, on your disk. It also has full SQL support, which means that I can practice my SQL queries on my databases and it can be easily visualized using an app like DB Browser for SQLite. 

The database file lives in tasks.db, which is automatically created once you run server.js.

To start the project:
- Clone the repo to your local disk
- Make a new directory and copy into it
- Run 'node server.js' in the terminal (preferably bash)

To test the API, I recommend using Postman and to visualize tasks.db, DB Browser for SQLite.
